# Security Policy

## Official Distribution Channels
To protect yourself from malware and impersonation attempts, please ensure you only download and install Minute of Silence from our official sources:
- **GitHub Releases:** Official repository `https://github.com/ChernegaSergiy/minute-of-silence`
- **Snap Store:** `snap install minute-of-silence`
- **Microsoft Store:** Search for "Minute of Silence" by Serhii Cherneha

> [!WARNING]
> We **never** distribute this application through third-party download sites, torrent trackers, or unofficial mirrors. If you find a website or repository offering a repackaged version of Minute of Silence, it is likely malware. Please report it immediately.

## Supported Versions
Security updates are provided for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.10.x  | :white_check_mark: |
| < 0.10  | :x:                |

## Reporting a Vulnerability
We take the security of this project very seriously. If you discover a security vulnerability, please **DO NOT** open a public issue.

Instead, please report it privately:
1. Send an email directly to **chernegasergiy3@gmail.com**.
2. Or use the [GitHub Security Advisories](https://github.com/ChernegaSergiy/minute-of-silence/security/advisories) feature to report it privately.

Please provide a clear description of the issue and steps to reproduce it. You should receive a response within 48 hours. We will work with you to verify the vulnerability and release a patch as quickly as possible.
